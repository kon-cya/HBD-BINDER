## 글 고치기
본문은 `story.txt`에 있어요.
- `# 제목` = 가운데 제목
- 줄바꿈 한 번 = 새 문단 (자동 들여쓰기)
- 빈 줄 한 개 = 문단 덩어리 사이 간격
- 빈 줄 두 개 이상 = 장면 전환 (빨간 픽셀 점 세 개)
- 한자는 Noto Serif TC(구글 폰트)로 표시

## 배경 음악
`audio/happy-birthday-8bit.mp3` — 음량은 index.html의 `VOLUME` 값(0~1)으로 조절.

## 편지 고치기
DEIMOS 네임텍을 누르면 나오는 편지는 `letter-deimos.txt`에 있어요. 줄바꿈 한 번 = 새 문단.
